# AI 결과 검수 기록

작업 도구: Claude Code (Claude Opus 5.5) · 작업일: 2026-11-19
원본: chanchan.kr (로컬 원본 `index.html` · `site.js`, 배포본과 같은 판임을 비교해 확인)

## 1. AI 가 만든 것과 확인 · 고친 것

| AI 가 만든 것 | 어떻게 확인했나 | 결과 · 고친 것 |
| --- | --- | --- |
| Next.js + Tailwind + shadcn/ui 뼈대 (`create-next-app`, `shadcn init/add`) | 생성된 `package.json` · `components.json` 확인. 새 shadcn 이 `cn` 이라는 npm 패키지를 쓰길래 저장소 출처 확인 | `cn` 은 shadcn-ui 공식 저장소(github.com/shadcn-ui/cn) 패키지임을 확인하고 그대로 사용 |
| 구간 11개 컴포넌트 + `src/content/*.ts` 데이터 | 빌드한 페이지의 글자를 chanchan.kr 배포본과 **스크립트로 한 조각씩 대조** (빠진 문구 · 더해진 문구 · 차례) | FAQ 답이 처음 HTML 에 없었음(Accordion 이 닫힌 칸을 그리지 않음) → `keepMounted` 로 고침. 그 뒤 빠진 문구 0. 더해진 것은 의도한 「앱 받기」 · 과제 안내 한 줄뿐 |
| 데모 결과 · 판정 문구 (원본은 자바스크립트가 그림) | 원본 스크립트 안의 한국어 문자열 29개를 뽑아 `src/content` 에 있는지 대조 | 모두 있음 |
| 신청서 검사 문구 | `site.js` 의 기관 신청서 안내 문구 6개 대조 | 모두 같음 |
| 히어로 제목 | 과제 지시문에는 「모르는 번호로 온 문자, 찬찬이 먼저 봅니다」로 적혀 있었음 | 원본 · 배포본 어디에도 없는 문장 → **원본 그대로** 「의심스러운 순간, 찬찬하게.」 사용 |
| 사전 신청(대기 명단) 신청서 | 지시문은 사전 신청 + 기관 문의 두 벌을 요구. 배포본은 2026-11-16 에 사전 신청을 뺐고, FAQ 도 「따로 알림 신청은 받지 않습니다」 | 사람이 결정: **배포본과 같이 기관 문의만** 둠 |
| 「출시 준비 중」 안내 창 | 원본에 이 창을 여는 버튼이 없음을 확인 | 사람이 결정: 위쪽 띠에 「앱 받기」 버튼(Dialog 열기)을 더함 |
| 글꼴 | 지시문은 「본문은 시스템 글꼴」이라 했으나, 원본은 본문까지 광양햇살체 한 벌(맑은 고딕 대체) | 원본 모습에 맞춰 전체를 광양햇살체로 둠 |
| 데모 결과를 다시 그리는 `key={Date.now()}` | React 규칙(렌더 중 순수해야 함) 검토 | 누를 때마다 올라가는 숫자(`runId`)로 바꿈 |
| 버튼 크기 | shadcn 기본 버튼은 높이 32px 로 어르신에게 작음 | 기본 52px · 작은 것 44px, 알약 모양으로 `button.tsx` 수정 |
| Dialog 바탕 | shadcn 기본은 옅은 검정 + 흐림 | 원본과 같은 진한 초록 반투명으로 바꿈 |

## 2. 동작 확인 (브라우저에서 직접)

| 확인한 것 | 결과 |
| --- | --- |
| 데모: 문자 고르기 → [확인하기] → 「확인하고 있어요」 1.15초 → 결과 / 다시 누르면 다시 보기 | 세 문자 모두 맞는 판정이 뜸. 확인 중에는 버튼이 잠김 |
| 판정 신호등: 램프를 누르면 아래 안내가 바뀜 | 됨 (`aria-pressed` 도 바뀜) |
| FAQ: 열기 · 닫기 · 둘 동시에 열기 | 됨 (원본 `<details>` 처럼 여러 개 열림) |
| 「앱 받기」 → 안내 창 → [닫기] · Esc | 열리고 닫힘. 닫히면 「앱 받기」로 초점이 돌아감 |
| 신청서 — 빈 채로 보내기 | 「기관명을 적어 주세요.」 → 칸을 하나씩 채우면 다음 빠진 칸 안내 |
| 신청서 — 이메일 모양이 틀림 | 「이메일 주소를 다시 봐 주세요. 예) name@example.com」 |
| 신청서 — 제대로 채워 보내기 | 「문의가 접수되었습니다.」 화면, 초점이 접수 안내로 옮겨감 |
| **보낼 때 네트워크 요청** | 브라우저 네트워크 기록에서 틀린 보내기 · 맞는 보내기 모두 **요청 0건** |
| 코드에 `supabase` · `fetch(` · `axios` 검색 | `src/` 에 코드로는 0건 (신청서 파일 주석에 「쓰지 않습니다」라는 설명만 있음) |
| 데스크톱(1366px) 화면 | 원본과 같은 차례 · 배치 |
| 폰 폭(375px) 가로 스크롤 | 처음에는 히어로 앞쪽 폰 그림이 오른쪽으로 32px 넘쳤음 → 히어로에 `overflow-x-clip` 을 주어 **가로 스크롤 0** |
