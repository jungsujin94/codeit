# QA 체크리스트 — 의심 문자 사례집

- 로컬: `npm run build` → `next start`, 저장소 = `.data/` 폴더 (2026-11-23)
- 배포: DEPLOY_URL, 저장소 = Vercel Blob (DEPLOY_DATE)
- 확인한 사람: 과제 제출자 + Claude Code (브라우저를 직접 조작해 확인)

| # | 시나리오 | 확인 방법 | 기대 결과 | 로컬 | 배포 |
| --- | --- | --- | --- | --- | --- |
| 1 | 빈 값 제출 | 등록 화면에서 아무것도 적지 않고 [남기기] | 보내지 않음. 「고칠 칸이 4곳 있습니다」 + 칸마다 안내, 제목 칸으로 초점 | ✅ | D1 |
| 2 | 잘못된 형식 — 글자 수 | 제목 1자, 문자 내용 3자 | 「제목은 2자 이상…」 · 「문자 내용은 5자 이상…」 | ⬜ | D2 |
| 3 | 잘못된 형식 — 그림 종류 | `.txt` 파일 고르기 | 「JPG · PNG · WEBP 그림만 올릴 수 있어요.」, 미리보기 없음 | ✅ | D3 |
| 4 | 잘못된 형식 — 그림 크기 | 3.9MB 파일 고르기 | 「그림은 3MB 까지 올릴 수 있어요…」 | ✅ | D4 |

| 7 | 등록 후 목록 반영 | 목록으로 이동 | 새 사례가 맨 앞, 「모두 N건」이 1 늘어남 | ✅ | D7 |
| 8 | 새로고침 후 유지 | 상세 · 목록에서 새로고침 | 같은 내용이 그대로 | ✅ | D8 |
| 9 | 수정 반영 | [고치기] → 판정 바꾸기 + 「그림 지우기」 → [저장하기] → 새로고침 | 새 판정, 「올린 그림이 없습니다.」, 「고친 때」가 생김. 옛 그림 파일도 저장소에서 지워짐 | ✅ | D9 |
| 10 | 그림 바꾸기 | [고치기] → 「다른 그림으로 바꾸기」 → 새 그림 | 새 그림이 보임 | ⬜ | D10 |
| 11 | 삭제 — 그만두기 | [지우기] → Esc | 창이 닫히고 [지우기]로 초점이 돌아감, 사례 그대로 | ✅ | D11 |
| 12 | 삭제 반영 | [지우기] → 창의 [지우기] | 목록으로, 「사례를 지웠습니다.」, 목록에서 사라짐, 그 주소는 「찾으시는 사례가 없습니다」 | ✅ | D12 |
| 13 | 없는 상세 주소 | `/cases/00000000-0000-0000-0000-000000000000`, `/cases/아무거나/edit` | 「찾으시는 사례가 없습니다」 + [사례 목록으로] | ✅ | D13 |
| 14 | 그림 없이 등록 | 그림 칸을 비우고 [남기기] | 상세에 「올린 그림이 없습니다.」, 목록 카드에 「그림 없음」 | ✅ | D14 |
| 15 | 업로드(저장) 실패 | 로컬: 그림 폴더를 일부러 막고 등록 | 「저장하지 못했습니다… 쓰신 내용은 그대로 남아 있습니다.」, 쓴 글 유지, 안내로 초점 | ✅ | — (로컬에서만 재현) |
